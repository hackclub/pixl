# Git and GitHub

^ Version control with Git keeps your codebase backed up, tracks your development history, and provides the public link required for Pixl reviews.

## 1. Initial setup

Verify Git is installed in your terminal (`git --version`). Set your global identity to match your GitHub account:

```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

## 2. Starting a repository

Inside your local project folder, run:

```bash
git init
git add .
git commit -m "initial commit"
```

Create a new repository on GitHub (leave it public), and link your local folder:

```bash
git remote add origin https://github.com/yourusername/my-project.git
git branch -M main
git push -u origin main
```

## 3. Daily workflow

As you build, save snapshots of your progress with regular commits:

```bash
git add .
git commit -m "add navigation menu and mobile styling"
git push
```

Write descriptive commit messages, because they provide clear proof of progress when reviewers inspect your build history.

## 4. Setting up a `.gitignore`

Avoid committing sensitive API keys, build artifacts, or dependency folders. Create a `.gitignore` file in your repository root:

```plaintext
node_modules/
.env
dist/
.DS_Store
```
